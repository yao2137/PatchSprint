# Tasks and Evaluation

- `tasks/`: traceable editing tasks, behavioral requirements, and data documentation.
- `harness/`: fixed-task replay, method comparisons, and metric collection.

Start with a small, manually inspectable task set, then establish development and held-out splits. Cover local edits, scattered edits, new logic, reordering, and rewrites, and record failures. See `../docs/EXPERIMENTS.md`. No dataset or evaluation program exists yet.
