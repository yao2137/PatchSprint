# AI Usage and Original Prompt Records

The course requires all AI prompts, including research, explanations, coding, debugging, and result analysis. Summaries can support an index but do not replace original records.

## Current State

AI conversations were used for project selection and design. The complete conversation history has not been imported into this repository. `PROJECT_CONTEXT.md` is a consolidated background document, not a complete prompt archive. This file does not yet satisfy the full archival requirement.

## Recording Process

- Preserve original conversations with dates and the tool/model when known.
- Use `docs/ai-prompts/` for English records. Keep non-English originals in a separate external archive so the repository remains English-only; an English translation must be labeled and must not replace its original.
- Retain user inputs, attachment references, and relevant responses so adopted suggestions remain traceable.
- Record what was accepted, modified, or rejected and how generated code or conclusions were verified.
- Check personal information and credentials before publication. Manage complete private records separately from the public index when necessary.
